# QR Code Scanner for PC

A free, fast QR code and barcode reader for Windows 10 and 11. Scan a QR code from your screen, a webcam, an image file, or the clipboard, and create your own QR codes for Wi-Fi, email, and contacts. Everything is processed locally, so your data stays on your device and the app works offline.

## Overview

Looking for a free QR code scanner for PC? This lightweight tool lets you scan QR codes and barcodes in seconds. Capture a code from your screen with the Windows Snipping Tool, open an image file, paste from the clipboard, or point a webcam at it. It reads 17 barcode types and includes a built-in QR code generator. Light and dark themes and a clean interface make it easy to use every day on both laptops and desktops

## Features

- **Scan QR code from screen.** Capture any part of your screen with the Windows Snipping Tool and decode it instantly.
- **Scan QR code with webcam.** Read codes from a webcam, OBS virtual camera, or the Windows Camera app.
- **Image and clipboard scanning.** Open an image file or paste a copied picture to read the code in one click.
- **Bulk scanning.** Decode a whole folder of images at once.
- **17 barcode types.** Reads QR codes and popular barcodes such as Code 128, EAN, UPC, Data Matrix, PDF417, and Aztec.
- **QR code generator.** Create QR codes from text with ready-made templates for Wi-Fi, email, and contact cards, plus custom colors and error correction.
- **Safe and private.** Everything is processed locally and nothing is collected. You can preview and inspect links before opening them.
- **Scan history.** View and export your scanned and created codes, or turn history off completely.
- **Light and dark themes.** A clean interface that fits your system style.

## Supported Barcode Types

The scanner reads QR codes and 16 other popular formats, including:

- QR Code
- Data Matrix
- PDF417
- Aztec
- Code 128
- EAN
- UPC

## Privacy

- All scanning and generation happen locally on your device.
- No data is collected or sent anywhere.
- The app works fully offline.
- Links can be previewed before opening, so you can check where a code leads.
- Scan history can be exported or disabled at any time.

## System Requirements

- Windows 10 or Windows 11
- A webcam (optional, only needed for camera scanning)


### Scan from the screen

1. Click the screen scan button.
2. Select the area with the QR code using the Windows Snipping Tool.
3. The result appears instantly.

### Scan with a webcam

1. Choose your camera (webcam, OBS virtual camera, or Windows Camera app).
2. Hold the code in front of the camera.

### Scan an image or clipboard

1. Open an image file, or paste a copied picture.
2. The code is decoded in one click.

### Bulk scan

1. Select a folder of images.
2. All codes in the folder are decoded at once.

### Create a QR code

1. Open the generator and enter your text, or choose a template (Wi-Fi, email, contact card).
2. Customize colors and the error correction level.
3. Save or copy your QR code.
